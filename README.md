## Análisis de Datos de Vehículos - Aplicación Web
## Descripción del Proyecto
Esta aplicación web interactiva permite explorar y visualizar datos de venta de vehículos usados. Los usuarios pueden crear diferentes tipos de gráficos para analizar las características y precios de los vehículos.

## Funcionalidades
- **Histogramas interactivos**: Visualiza la distribución del odómetro de los vehículos
- **Gráficos de dispersión**: Explora la relación entre odómetro y precio
- **Interfaz intuitiva**: Botones fáciles de usar para generar visualizaciones

## Tecnologías Utilizadas
- Python
- Streamlit (framework para aplicaciones web)
- Plotly Express (visualizaciones interactivas)
- Pandas (manipulación de datos)

## Cómo Ejecutar la Aplicación
1. Activar el entorno virtual: `conda activate vehicles_env`
2. Ejecutar la aplicación: `streamlit run app.py`
3. Abrir el navegador en la URL que aparece en la terminal
